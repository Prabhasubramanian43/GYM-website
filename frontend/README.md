# FitFuel Frontend (React + Vite)

A beginner-friendly responsive frontend demo for FitFuel healthy gym food.

## Run in VS Code

1. Extract this ZIP file.
2. Open the extracted `fitfuel-frontend` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the localhost address printed in the terminal (usually http://localhost:5173).

## Included

- Home, About, Products, Cart, Checkout, Order Success and Contact pages
- Responsive Navbar and Footer
- Search and category filters for all 38 menu entries/plans
- Food customization options and working cart state
- Cart and demo orders stored in browser LocalStorage
- Sample prices for frontend demonstration only
- `src/assets/home.jpg` hero food image extracted from the screenshot supplied in the conversation

## Important notes

- This is frontend-only. No Node/Express/MongoDB backend, payment processing, real order dispatch or server-side contact form is connected.
- Nutrition values are approximate and should be checked before commercial use.
- The same bundled food image is reused for cards as a placeholder. Replace `src/assets/home.jpg` or update image paths with your own licensed food photography.
- Contact details are demo placeholders.
